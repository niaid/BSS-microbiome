## Authors

Metagenomics code by Lauren Krausfeldt, BCBB/OCICB/OSMO/OD/NIAID/NIH

Metabolomics code by Ian LaCroix, PCS/RTB/DIR/NIAID/NIH

## Description

Scripts and other code for analysis of sequencing data, metabolomics data, and other immune data from the study exploring the effect of bismuth subsalicylate on the gut microbiome.
