## Multi-omic analysis

This directory contains all scripts and code used to analyze the metabolomes and make raw figures for Band et al. (2026). Specifically, these analyses correspond to reviewer request for multi-omics analyses between somalogic proteomics, single cell immune data, metagenomics, and metabolomics.



### Data availability

The metabolomics data can be accessed through FigShare: https://doi.org/10.6084/m9.figshare.30203644.v2

Additional information is available upon reasonable request.
