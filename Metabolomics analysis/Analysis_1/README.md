## Metabolomic analysis

This directory contains all scripts and code used to analyze the metabolomes and make raw figures for Band et al. (2026). Specifically, main body figure 2 bubble plots and Sankey diagram. As well as extended data figure 6 matrix bar plots, which were generated using an in house developed package. 

Johnson, R. C., Lacroix, I., & Schwarz, B. matrixBP: An R package to generate matrix bar plots (0.1.1). Zenodo., <https://doi.org/10.5281/zenodo.14755324> (2025).

### Data availability

The metabolomics data can be accessed through FigShare: https://doi.org/10.6084/m9.figshare.30203644.v2
